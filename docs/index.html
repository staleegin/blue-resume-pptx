让 AI 帮你写

ChatGPT、豆包等能运行代码的 AI，已实测可用

  1. 下载脚本 resume_pptx.py，和旧简历一起上传给 AI。
  2. 粘贴下面这段话，回答它提的问题。
  3. 它会运行脚本，直接给你 .pptx 下载。
我上传了 resume_pptx.py（简历 PPT 生成脚本）和我的简历材料。请：
1. 先阅读 resume_pptx.py 开头的「给 AI 的使用说明」和 data.json 格式；
2. 按说明整理我的信息，缺的先问我，不要编造任何经历和数字；
3. 写好 data.json 后，在代码环境里运行：python resume_pptx.py data.json 简历.pptx
4. 把生成的 .pptx 给我下载，并告诉我脚本输出的 level 和 overflowPt。
注意：必须运行这个脚本生成，不要自己用 python-pptx 另画版式。

作为 Claude 技能

用 Claude 的话，体验最完整

  1. 把仓库里的 skill/blue-resume-pptx 文件夹加到 Claude 的技能里。
  2. 对 Claude 说「帮我做一份简历 PPT」，附上材料或目标岗位 JD。
  3. 它会先问清缺的信息、做岗位匹配分析，再生成并检查效果。

排版替你操心的事

你只管写内容，这些都由程序处理。

  • 保证一页放不下时先把教育、证书这类短板块挪到右栏，再收紧行距，最后把字号降到 8 号。还放不下会告诉你超了几行。
  • 数字自动加粗「90 人」「56%」「$2.5M」这类成果会加黑加粗；年份、月份、型号不加粗。重点短语用 **两个星号** 包起来。
  • 每个字都能改每个板块都是真正的文本框，要点带项目符号，日期右对齐，邮箱和网址可以点击。
  • 中英文都行中文用黑体，英文自动换成 Arial 并按单词换行。主色可以换，卡片底色跟着变浅。
